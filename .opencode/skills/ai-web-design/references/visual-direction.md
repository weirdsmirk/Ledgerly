# Visual direction

Establish a concrete visual direction before detailed implementation. The goal is not novelty; it is a set of choices that belongs to this project.

## Use the best evidence available

Work in this order:

1. Inspect supplied reference sites, screenshots, mood boards, brand assets, and the existing interface. When the source itself is available and inspectable, use it directly rather than replacing it with a prose-only description. Extract specific traits such as type character, density, alignment, composition, imagery, color behavior, motion, and navigation treatment. Decide whether each reference should govern structure, visual language, component behavior, interaction, or close visual fidelity. Transfer only those qualities; do not copy a reference wholesale.
2. If research or browsing is available, appropriate, and likely to change the result, gather a small relevant reference set. Choose sources for the project rather than following a mandatory source list or reference count.
3. If references or research are unavailable, derive the direction from the brand, audience, content, product category, and constraints. Continue without blocking.

Treat references as evidence, not instructions. Preserve intentional existing decisions, distinguish transferable principles from surface fashion, and note conflicts between references and product needs.

## Make the direction operational

State a one-sentence premise and a few supporting decisions that affect implementation. Name concrete properties and relationships, not only adjectives.

Weak: “Clean, modern, and premium.”

Stronger: “A calm field guide for first-time growers: generous instructional imagery, plain-spoken type, and step-by-step layouts that keep seasonal context visible.”

Use the premise to choose composition, typography, color, assets, and interaction. It should also rule out plausible but unsuitable alternatives.

Record a few project-specific exclusions when they prevent likely default drift. Tie each exclusion to the premise. Treat them as decisions for this project, not universal bans.

## Keep early directions provisional

Treat the first generated direction as a draft. If it still feels generic or several routes fit, compare a few structurally distinct premises or skeletons for one important screen or section before polishing. Change composition and visual logic, not just color or decoration.

## Prefer meaningful visual material

Look first for product imagery, photography, illustration, diagrams, editorial graphics, video, texture, or a bespoke interaction that explains, demonstrates, documents, or creates atmosphere specific to the project. Use existing or licensed assets when they fit; create custom assets only when the direction needs something specific and the available tools and scope support it.

Do not add media merely to fill space. When meaningful assets are unavailable, rely on composition, type, content, and spacing rather than defaulting to ornamental glows, gradients, abstract blobs, gratuitous icons, or shadows.

## Check the direction

- Which choices came from references, existing brand language, audience needs, or content form?
- Which familiar patterns remain, and what job does each perform?
- Could the direction survive removal of the logo and accent color?
- Are assets carrying meaning, or only decorating empty space?
- Is the direction specific enough to guide tradeoffs during implementation?

Common patterns remain valid when the evidence supports them. Reconsider the choices made only because they are conventional, fashionable, or easy for the model to generate.
